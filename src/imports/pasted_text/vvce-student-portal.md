Design System & Guidelines
Color Palette
Primary: #091A7A (Deep Navy Blue)
Secondary: #ADC8FF (Light Blue)
Success: #10B981
Warning: #F59E0B
Error: #EF4444
Neutral: #6B7280
Typography
Font Family: Lexend, sans-serif (throughout the entire application)
Never override base typography unless specifically requested
Typography is controlled by the design system
Glass Morphism System
Use backdrop-blur-lg (16px) for all glass morphism effects
Always use bg-card-glass or bg-glass utility classes
Consistent borders: border border-white/20 or border-white/30
Shadow hierarchy using CSS custom properties
Animation & Interaction
Mobile: Use whileTap={{ scale: 0.95 }} for touch feedback only
Desktop: Add whileHover effects for better UX
No cursor pointer needed on mobile; add hover states for desktop
Minimum touch target size: 44px × 44px for accessibility
Keep animations subtle (0.95-1.05 scale range)
Performance first: prefer transform animations
Responsive Design
Mobile-first approach: Design for mobile, enhance for desktop
Breakpoints: Use Tailwind's responsive classes (sm, md, lg, xl, 2xl)
Layout: Single column on mobile, multi-column grid on desktop where appropriate
Navigation: Hamburger menu on mobile, sidebar or horizontal nav on desktop
Typography: Scale font sizes appropriately for different screen sizes
